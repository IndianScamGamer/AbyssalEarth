## Recommended Blender Session Order

1. **Session 0 (5 min, no Blender):** Create `BP_AbyssalExplorerCharacter` in UE editor, assign `SKM_Manny` as placeholder mesh. This unblocks all PIE testing.
2. **Session 1:** Crystal clusters (S, M, L variants) — fastest, highest density of use, immediate visual improvement.
3. **Session 2:** Foreground ledge + rock arch/overhang — establishes the First Overlook composition.
4. **Session 3:** Bridge span kit (A, Broken, PlatformNode) — makes the route traversable.
5. **Session 4:** Hex collector tile + cluster system — Collector Array landmark.
6. **Session 5:** Orb frame + hub + beam emitter nodes — central apparatus.
7. **Session 6:** Ancient Gate wall + detail ring + panels — completes the right-side vista.
8. **Session 7:** Background depth kit (towers, hanging slabs, distant spires).
9. **Session 8:** Human survey kit (crate, lamp, cable coil, console, platform, railing).
