# Concept Art Generation Sort

This folder is the sorted version of the generated concept art dump. The old `Concept Art Generation/` holding folder was removed; its contents now live directly under `Content/ArtDirection/Concepts/`.

## Production Buckets

- `00_Elevator_Shaft_User_Made_Do_Not_Modify/`: elevator/descent-shaft images preserved as user-made references.
- `01_Luminous_Rift/`: Luminous Rift environment, landmarks, atmosphere, and traversal shots.
- `02_Glassroot_Forest/`: Glassroot Forest map concepts.
- `03_Inner_Sea/`: Inner Sea map concepts.
- `04_Fossil_Sky/`: Fossil Sky map concepts.
- `05_Gravity_Well/`: Gravity Well map concepts.
- `06_Mantle_Garden/`: Mantle Garden map concepts.
- `07_Later_Regions/`: later-region experiments and expansion concepts.
- `08_Human_Explorer/`: explorer character, scanner use, survey camp, and human scale references.
- `09_Material_Studies/`: basalt, machine-stone, crystal, orb, and gold-beam material references.
- `10_Composition_Studies/`: art-direction composition and lighting studies.
- `11_Narrative_Beats/`: first-step, discovery, gate, second-sky, and scale narrative shots.
- `12_Asset_Details/`: orb apparatus, collector panel, towers, rock arch, lamp, and hanging slab references.
- `13_Panoramas/`: ultrawide panorama studies.
